# Melba v0.3.13 — broader Linux compatibility

Melba v0.3.13 is a paired GUI/daemon release built against **glibc 2.35**, not
the glibc 2.43 baseline used by v0.3.12.

## Changes

- Signed portable archives for x86_64 and ARM64, with `melba` and `melbad`
  packaged together and verified by an Ed25519-signed SHA-256 manifest.
- The prebuilt Linux installer installs missing runtime libraries through
  native package managers where supported. Optional ALAC staging remains
  opt-in and uses a separate third-party runtime.
- A post-install `melbad wrapper setup` can provision missing staging tools
  on Arch/CachyOS, Debian/Ubuntu, and Fedora.
- Installation documentation for Nix/NixOS, which uses a **separate native
  Nix package** with Nix-managed upgrades, not the FHS portable installer.

## Compatibility evidence

The x86_64 release candidate was executed in real containers on Ubuntu
22.04, 24.04, 26.04, Debian 12, Debian 13, Fedora 43, Fedora 44, and Arch.
Both x86_64 and ARM64 binaries were built in the Ubuntu 22.04 baseline
and passed GNU ABI verification: `melba` requires at most `GLIBC_2.35`,
and `melbad` at most `GLIBC_2.34`.

This proves launch/version and shared-library compatibility in those
containers, **not** Apple sign-in, desktop rendering, physical audio output
or ALAC playback. ARM64 was build-verified on a native ARM64 runner,
not run-verified on target devices. The separate Nix paired package remains
pinned to the previous verified release until its hashes are updated.

## Integrity

The release contains both executable archives for each architecture,
third-party notices, `checksums.txt`, `checksums.txt.sig`, and the existing
publisher verification key. Do not install unsigned CI candidate artifacts.
