# Melba v0.4.0-alpha.1: pre-release for alpha testing

Melba v0.4.0-alpha.1 is a signed pre-release for testing the 0.4.0 changes and the GUI update path ahead of the stable 0.4.0 release. The latest stable release remains **v0.3.30**.

## New

- **Select a song in Next up directly.** One command selects the requested queue occurrence without opening intervening songs. The original context, remaining shuffle plan and visited history are preserved, including duplicate songs.
- **Settings that fit the window.** A bounded, centered content column uses wider windows without unbounded text lines. Complex controls move below readable descriptions when necessary; narrow quality choices stay grouped and ordered. Output selection and refresh no longer share an undersized slot, and long selected values have full-value tooltips. Small switches remain beside their labels.
- **Developer-only alpha update opt-in.** Setting `"update_channel": "alpha"` in `settings.json` while Melba is completely closed allows the GUI updater to receive signed pre-releases (`v0.4.0-alpha.1` → later alphas → `v0.4.0`) using the same publisher signature verification and paired `melba`/`melbad` rollback safety. No Settings UI control is added; omitting the field or setting `"stable"` keeps standard stable-only updates.

## Fixed

- **Next and Previous supersede obsolete loading.** Both directions share cancellation and navigation, including mixed bursts. Established source HTTP connections, wrapper TCP reads and pipe readers can be interrupted without waiting for the old response or creating a loader thread per press.
- **Late work cannot undo a selection.** Manual navigation invalidates older GUI context resolution. Cancelled work is not treated as a failed track or a reason to try a preview; cancelled preview downloads do not leave partial cache entries. Speculative segment workers have a process-wide bound.
- **Previous keeps its playback rule and actual history.** A visited song beyond three seconds restarts first; subsequent presses go backward. Unfinished loading candidates do not inherit the old position or count as visited merely because their URI matches another occurrence.

## Dependency maintenance

The lockfile updates `quinn-udp` to 0.5.16 for [RUSTSEC-2026-0538](https://rustsec.org/advisories/RUSTSEC-2026-0538). Existing audit warnings retain their existing classification; no advisory is suppressed to pass this pre-release.

## Updating

Update **both `melba` and `melbad`**, then fully quit and relaunch Melba so its playback daemon restarts too. The direct-selection command requires the matching daemon. Existing settings and queue files retain their format; this pre-release introduces no data-format migration.

## Known pre-release status and limits

- **Authentication gates remain open for stable 0.4.0.** Fresh native sign-in / 2FA, expired-session recovery and GUI sign-out have not yet been verified end-to-end on this release candidate.
- Linux is the runtime-tested platform. Cross-platform compile checks and ARM64 builds do not establish physical audio acceptance on those systems. Audio-path limitations and the external, user-supplied ALAC service requirement remain unchanged.
