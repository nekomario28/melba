# Melba v0.4.0: responsive playback controls and clearer settings

Melba v0.4.0 brings direct queue selection, responsive Next/Previous during loading, and a settings layout that adapts to the window. It retains the Linux portable package format and established publisher signing key.

## New

- **Select a song in Next up directly.** One command selects the requested queue occurrence without opening intervening songs. The original context, remaining shuffle plan and visited history are preserved, including duplicate songs.
- **Settings that fit the window.** A bounded, centered content column uses wider windows without unbounded text lines. Complex controls move below readable descriptions when necessary; narrow quality choices stay grouped and ordered. Output selection and refresh no longer share an undersized slot, and long selected values have full-value tooltips. Small switches remain beside their labels.

## Fixed

- **Next and Previous supersede obsolete loading.** Both directions share cancellation and navigation, including mixed bursts. Established source HTTP connections, wrapper TCP reads and pipe readers can be interrupted without waiting for the old response or creating a loader thread per press.
- **Late work cannot undo a selection.** Manual navigation invalidates older GUI context resolution. Cancelled work is not treated as a failed track or a reason to try a preview; cancelled preview downloads do not leave partial cache entries. Speculative segment workers have a process-wide bound.
- **Previous keeps its playback rule and actual history.** A visited song beyond three seconds restarts first; subsequent presses go backward. Unfinished loading candidates do not inherit the old position or count as visited merely because their URI matches another occurrence.

## Updating

Update **both `melba` and `melbad`**, then fully quit and restart the desktop session. The direct-selection command requires the matching daemon. Existing settings and queue files retain their format; this release introduces no data-format migration.

## Verification

This document is a release candidate until the release gate is closed. Matching-source local regressions cover blocked-source cancellation before the old source is released, actual stalled HTTP header/body sockets, queue history, mixed directions and responsive widget geometry. The maintainer accepted the installed playback/navigation and settings builds. Final 0.4.0 CI, upgrade, authentication and playback acceptance must be recorded before publication; earlier local acceptance does not substitute for those gates.

## Limits

Linux is the runtime-tested platform. Cross-platform compile checks and ARM64 builds do not establish physical audio acceptance on those systems. Cancellation is not an unconditional deadline for native DNS/connect establishment, regular-file kernel stalls or native CDM calls. Audio-path limitations and the external, user-supplied ALAC service requirement remain unchanged. EQ, crossfade, normalization and Atmos are not added by this release.
