# README assets

`melba-album.png` is an actual Melba window capture using the built-in demo
library (`--demo`), not a mockup. It is cropped to the album content area so
the sidebar playlists, account avatar and player bar are not shown. It contains
no account data, tokens or personal library.

The demo library uses public album artwork and generic track metadata. Replace
the asset with another demo capture if the UI changes; do not substitute a
synthetic illustration and call it a screenshot.
